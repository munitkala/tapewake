# Contributing

Thanks for wanting to help! Bug reports, test results on other tapes and cards, and pull requests are all welcome.
Results from AMD and Intel graphics cards are especially useful: that support is new in 0.2.1 and has had little
testing.

## Reporting a problem

Open an issue with the bug report form. The most useful things to include:

- your computer (Windows or Mac version), graphics card and tapewake version
- which step it stopped at (the progress window shows it)
- the last lines of `run.log` from the job's work folder

Before you paste a log, remove anything private: your name in folder paths, file names of family videos, and so
on. Please don't attach footage of people who haven't agreed to it being shared.

## Pull requests

- Keep changes focused, one thing per pull request.
- Match the style of the code around it.
- For anything that changes how a restoration looks or sounds, say what you tested it on and include a before /
  after frame if you can.
- Don't copy code from other projects into tapewake. Using a library is fine (add it to `THIRD_PARTY.md` with its
  licence), but copied code brings that project's licence with it. This matters most for the face models, which
  are non-commercial only.

By sending a pull request you agree that your contribution is released under the MIT licence, like the rest of
tapewake.

## Be decent

Be kind and patient with each other. Plenty of people here are restoring tapes of family members who have passed
away, so remember there's a person on the other side.
